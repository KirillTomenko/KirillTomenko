## 📊 Proposal Generator — конструктор КП с контролем честности

По заявке клиента с фриланс-биржи генерирует коммерческое предложение: находит реальные 
совпадения с портфолио по блокам задачи, честно считает цену (без искусственного занижения 
под бюджет клиента и без завышения за счёт непроверяемых часов) и помечает прогоны, 
требующие ручной проверки.

**Результат для бизнеса:**
- цена и заявленный опыт подтверждены реальным портфолио, а не выдуманы моделью;
- защита от типичных ошибок LLM: агрегаты (итоговая цена, проценты) пересчитываются 
  детерминированно, а не берутся на слово;
- полный аудит-лог каждого прогона — для контроля качества и разбора спорных случаев;
- ускоряет подготовку отклика без потери честности перед клиентом.

**Stack:** Python · FastAPI · SQLite · OpenAI API · Pydantic · Docker

**Repository:** 
https://github.com/KirillTomenko/proposal-generator

## 🧠 Knowledge System — база знаний команды с проверяемыми ответами

Отвечает на вопросы по внутренним документам команды: гибридный поиск (по ключевым словам + 
векторный) находит источники, LLM формирует ответ строго на их основе, а прогоны без 
достаточных источников автоматически помечаются для проверки человеком — вместо того чтобы 
модель придумывала ответ при нехватке данных.

**Результат для бизнеса:**
- быстрый поиск по внутренним документам вместо ручного перебора файлов;
- каждый ответ подкреплён реальным источником — можно проверить, а не просто поверить модели;
- гибридный поиск (BM25 + векторный) устойчивее к формулировкам вопроса, чем один способ поиска;
- полный аудит-лог всех запросов для контроля качества.

**Stack:** Python · FastAPI · SQLite · ChromaDB · OpenAI API · Docker · GitHub Actions CI

**Live demo:** https://knowledge-system-ln80.onrender.com
**Repository:** 
https://github.com/KirillTomenko/knowledge-system
